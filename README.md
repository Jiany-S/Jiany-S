## 🔬 Featured Work

### 🧠 [Personalized Human-State Forecasting](https://github.com/Jiany-S/twin-psych-risk-model)

> Physiological modeling and multi-rate supervisory replay for human–robot collaboration.

* Built held-out-subject stress modeling pipelines using WESAD physiological data
* Achieved **AUROC 0.768 across 11,988 evaluation windows**
* Implemented personalized calibration using subject-specific baseline segments
* Developed fast current-state detection and multi-horizon forecasting pipelines
* Designed a supervisory replay architecture separating ML recommendations from deterministic physical-safety rules

**Tech:** Python · PyTorch · XGBoost · Temporal Fusion Transformers · Signal Processing

---

### ⚽ [FIFA World Cup 2026 Forecasting](https://github.com/Jiany-S/WorldCup_ML)

> Leakage-safe probabilistic forecasting for the official 48-team tournament format.

* Built regularized Poisson goal models with team attack and defense effects
* Engineered temporal-form, team-strength, squad-quality, rating, and optional event/xG features
* Processed **460K+ raw football rows**, including matches, lineups, pressure data, and player records
* Added chronological backtests, calibration diagnostics, and model audits
* Simulated full tournaments using **100K Monte Carlo runs**

**Tech:** Python · pandas · scikit-learn · XGBoost · Monte Carlo Simulation

---

### 📈 [Inflation Nowcasting with Machine Learning](https://github.com/Jiany-S/Inflation-Nowcast)

> Next-month U.S. CPI forecasting using leakage-safe macroeconomic features.

* Built a reproducible pipeline using monthly FRED economic data
* Benchmarked naive models, ARIMA, Ridge, Lasso, XGBoost, and LSTM architectures
* Achieved best held-out performance with XGBoost:

  * **MAE: 0.158**
  * **sMAPE: 5.73**
  * **MASE: 0.547**
* Added rolling backtests, uncertainty intervals, feature importance, ablations, and automated reports

**Tech:** Python · TensorFlow · XGBoost · scikit-learn · FRED · Time-Series Modeling

## 📄 Research

### Human–Robot Collaboration and Cognitive Digital Twins

As a Research Assistant at the American University of Beirut, I work on machine-learning-driven physiological modeling and digital-twin systems for adaptive human–robot collaboration.

I co-authored an **EC3 2026 conference paper** on role-aware human–robot collaboration in 3D concrete printing, proposing a **Human–Robot–Site taxonomy** and predictive digital-twin framework for construction safety.

### Cost-Aware LLM Decision Policies

My current Final Year Project studies whether an LLM can learn when it should:

* Answer directly
* Retrieve additional evidence
* Verify its response
* Abstain when evidence is insufficient

The objective is to improve correctness and evidence support while reducing unnecessary tool calls, token usage, and computational cost.
